## 双版本对齐说明

- **机器版**：`data/task-tracker.json` — JSON 结构化，可被脚本/CI/Agent 直接解析
- **人类版**：本文件 (`docs/task-tracker-dashboard.md`) — Markdown 表格，可打印、可手动勾选
- **对齐规则**：Task ID（P1.01 ~ P6.14）在两版本中完全一致，更新进度时两文件必须同步修改
- **Phase 状态联动**：Phase 状态由其所有子任务状态自动推断（全部 completed = Phase completed）
